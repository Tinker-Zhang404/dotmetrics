DotMetrics v1.0.0 for Windows
================================

1. Keep DotMetrics.exe and the _internal folder together.
2. Run DotMetrics.exe from this folder. Do not move the EXE by itself.
3. The detector loads and warms up in the background. Wait for
   "Detector: ready" before starting analysis.
4. See USER_GUIDE.md for the complete workflow and MODEL_CARD.md for
   intended use and limitations.

The application stores logs and temporary files under the current user's
local application-data directory. It does not modify source TEM images.
